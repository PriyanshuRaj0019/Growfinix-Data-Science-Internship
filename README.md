## Technology Stack

Python, Pandas, Matplotlib, Seaborn, BeautifulSoup, Requests, Streamlit, Plotly, SQL, SQLite, SciPy and Statsmodels.

## How to Run Locally

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Run the dashboard:

```powershell
streamlit run Task-1-Project-Development/Tour-Enquiry-Dashboard/src/app.py
```

Run individual technical projects from their `src` folders using Python.
