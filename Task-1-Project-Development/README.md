# Task 1 - Project Development & Documentation

## Project Selected
Interactive Tour Enquiry Analytics Dashboard

## Objective
Build an interactive dashboard that analyses customer tour enquiries and helps identify business patterns such as peak enquiry time, popular destinations, lead source performance and booking conversion.

## Folder Included
`Tour-Enquiry-Dashboard/`

## Technologies Used
Python, Pandas, Streamlit and Plotly.

## Key Features
- Interactive filters
- KPI cards
- Total enquiries
- Confirmed bookings
- Booking conversion rate
- Median customer budget
- Popular destination analysis
- Peak enquiry time analysis
- Lead status analysis
- Geographic distribution analysis

## How to Run

```powershell
pip install -r ../../requirements.txt
streamlit run Tour-Enquiry-Dashboard/src/app.py
```

## Output
The project produces a Streamlit dashboard that allows users to interactively explore enquiry data and understand customer demand.
