# Interactive Tour Enquiry Analytics Dashboard

## Objective
To develop an interactive analytics dashboard for analysing customer tour enquiries and identifying patterns in customer demand.

## Business Problem
Travel businesses receive customer enquiries from multiple destinations, sources and time periods. Without a dashboard, it becomes difficult to quickly identify demand patterns and conversion performance.

## Technologies
- Python
- Pandas
- Streamlit
- Plotly

## Dataset
The dataset contains customer enquiry records with fields related to destination, source, status, enquiry timing, geography and customer budget.

## Features
- Total enquiry KPI
- Confirmed booking KPI
- Booking conversion rate
- Median customer budget
- Destination-wise demand analysis
- Peak enquiry time analysis
- Lead status analysis
- Geographic distribution analysis
- Interactive filters

## Workflow
Data Collection -> Data Cleaning -> Data Transformation -> KPI Creation -> Visualization -> Dashboard Development -> Business Insights

## Key Insights
The dashboard helps identify:
- Most demanded tour destinations
- Peak enquiry periods
- Strongest customer-acquisition sources
- Booking conversion performance
- Customer location patterns

## Run Command

```powershell
streamlit run src/app.py
```

This task strengthened practical skills in Pandas data manipulation, Streamlit app development, Plotly visualization and business-focused dashboard design.
