# Growfinix Internship - Learning Documentation & Progress Tracking

## Internship Track
Data Analytics / Data Science

## Month 1 Objective
Develop practical knowledge of Python, data cleaning, exploratory data analysis, web scraping, dashboarding, SQL integration and statistical analysis.

## Week 1 - Python, Pandas and EDA

### Topics Learned
- Loading datasets with Pandas
- DataFrame operations
- Missing value analysis
- Duplicate detection
- Data type conversion
- Outlier detection
- IQR method
- Feature engineering
- Exploratory Data Analysis

### Practical Work
Real Estate Exploratory Data Analysis.

### Tools Used
Python, Pandas, Matplotlib and Seaborn.

### Key Learning
Raw datasets normally require significant cleaning before meaningful analysis can be performed.

## Week 2 - Data Extraction and Web Scraping

### Topics Learned
- HTML structure
- CSS selectors
- HTTP requests
- BeautifulSoup parsing
- Data extraction
- Data cleaning
- CSV export

### Practical Work
Automated Real Estate Data Extraction.

### Tools Used
Python, Requests, BeautifulSoup and Pandas.

### Key Learning
Web information can be converted into structured analytical datasets using automated extraction pipelines when scraping is done responsibly.

## Week 3 - Dashboard Development

### Topics Learned
- Streamlit application development
- Plotly visualizations
- KPI creation
- Interactive filtering
- Business dashboard design
- Customer behaviour analysis

### Practical Work
Interactive Tour Enquiry Analytics Dashboard.

### Key Learning
Dashboards should communicate business decisions, not just display charts.

## Week 4 - SQL and Statistical Analysis

### Topics Learned
- SQL JOINs
- GROUP BY
- Aggregate functions
- CTEs
- Window functions
- SQLite
- Pandas-SQL integration
- A/B testing
- Hypothesis testing
- p-value
- Confidence interval

### Practical Work
SQL Database Extraction and A/B Testing Analysis.

### Key Learning
SQL, Python and statistics can be combined to produce reliable analytical conclusions.

## Overall Learning
The internship helped me understand the complete analytics workflow:

Raw Data -> Cleaning -> Exploration -> Database Querying -> Visualization -> Statistical Analysis -> Business Decision
