# Final Presentation Script

Hello everyone, I am Priyanshu Raj. This is my final presentation for the Growfinix Data Analytics Internship.

During this internship, I worked on a complete analytics workflow covering data cleaning, exploratory data analysis, data extraction, dashboard development, SQL integration and statistical analysis.

The first project was Real Estate Exploratory Data Analysis. In this project, I cleaned a messy property dataset, handled missing values, detected outliers and created visualizations to understand price distribution and neighbourhood-wise property trends.

The second project was Automated Real Estate Data Extraction. I used Python, Requests, BeautifulSoup and Pandas to extract structured data from HTML property listings and export the cleaned results into a CSV file.

The third project was an Interactive Tour Enquiry Analytics Dashboard. Using Streamlit, Plotly and Pandas, I created a dashboard to analyse enquiry volume, popular destinations, booking conversions, peak enquiry times and customer distribution.

The fourth project focused on SQL Database Extraction and Integration. I used SQL JOINs, aggregate functions, CTEs and window functions to extract insights from a relational SQLite database. The SQL results were loaded directly into Pandas for further analysis.

The fifth project was A/B Testing and Statistical Analysis. I compared conversion rates between two experiment groups using hypothesis testing, p-values and confidence intervals. This helped me understand why business decisions should be supported by statistical evidence.

Overall, this internship helped me understand how raw data moves through a complete analytics pipeline: collection, cleaning, exploration, querying, visualization, statistical testing and business decision-making.

Thank you.
