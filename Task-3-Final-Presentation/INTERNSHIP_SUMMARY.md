# Growfinix Data Analytics Internship - Final Summary

During my Growfinix internship, I completed practical projects covering multiple stages of the data analytics lifecycle.

The internship started with data cleaning and exploratory data analysis. I then worked on automated data extraction, interactive dashboard development, relational database analysis and statistical experimentation.

## Projects Completed

1. Real Estate Exploratory Data Analysis
2. Automated Real Estate Web Data Extraction
3. Interactive Tour Enquiry Dashboard
4. SQL Database Extraction and Integration
5. A/B Testing and Statistical Analysis

## Technical Skills Developed

Python, Pandas, Matplotlib, Seaborn, BeautifulSoup, Requests, Streamlit, Plotly, SQL, SQLite, SciPy and Statsmodels.

## Major Learning

The most important learning from the internship was understanding how individual technical skills fit into an end-to-end data analytics workflow.

Instead of analysing data only through isolated scripts, I learned how data can move from collection and cleaning to analysis, visualization, statistical validation and business decision making.

## Final Outcome

The internship helped me build a practical portfolio that demonstrates data cleaning, EDA, scraping, dashboarding, SQL integration and statistical decision-making.
